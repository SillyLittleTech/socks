# Socks

Tips for staying safe in a digital world.

Socks is a lightweight Starlight site for practical, calm digital safety guidance:
least-access habits, scam-aware workflows, privacy tools, online identity, and the path from learning into building.

## Local development

Install dependencies, then start the docs site:

```sh
npm install
npm run dev
```

Open the local Keystatic editor at `http://127.0.0.1:4321/keystatic`.

Production builds are static by default. To experiment with a hosted Keystatic editor later, set `ENABLE_KEYSTATIC=true` and add an Astro server adapter for the target host.

## Useful commands

```sh
npm run check
npm run build
npm run preview
```
