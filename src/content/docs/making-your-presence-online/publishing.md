Publishing does not have to start with a full custom site.

## Common paths

| Path | Good for | Tradeoff |
| --- | --- | --- |
| Social profile | Fast sharing and discovery | Platform rules and feed pressure. |
| No-code site | Quick portfolio or landing page | Less portability. |
| Static site | Durable, fast, low-cost publishing | Some setup and Git comfort. |
| CMS-backed site | Frequent editing and collaboration | More moving parts. |
| Personal domain | Portable identity and email routing | Renewal and DNS management. |

## Domain basics

Keep domain registrar access secure. Turn on registrar lock, use strong MFA, and document DNS records before changing them.
