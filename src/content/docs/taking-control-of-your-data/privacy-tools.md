Privacy tools are most useful when they solve a specific problem you actually have.

## Useful categories

| Tool type | Helps with | Watch for |
| --- | --- | --- |
| Password manager | Unique credentials and secure notes | Protect the main account well. |
| Ad blocker | Malvertising, trackers, clutter | Use reputable filter lists. |
| Browser profiles | Separating identities and contexts | Keep extensions minimal. |
| VPN | Network-level privacy on untrusted networks | It does not make you anonymous. |
| Payment aliases | Merchant exposure and subscription control | Understand fees and limits. |
| Security keys | Phishing-resistant account login | Enroll at least two keys. |

## Tool choice rule

Pick tools that make your normal behavior safer. If a tool is so annoying that you keep turning it off, adjust the setup.
