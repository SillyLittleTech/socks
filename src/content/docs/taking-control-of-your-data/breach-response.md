Breach notices are stressful, but most of the response is a checklist.

## If a password was exposed

1. Change the password on the affected account.
2. Change it anywhere else you reused it.
3. Add MFA if the account supports it.
4. Check recent sessions, devices, forwarding rules, and connected apps.
5. Save the lesson: unique passwords make the next breach smaller.

## If a card was exposed

Freeze or replace the card if needed. For virtual cards, close or rotate the affected card. Check recent transactions and subscription dependencies.

## If a phone number was exposed

Expect more scam calls and texts. Move high-value account recovery away from SMS where possible, and ask your carrier about account PINs or port-out protection.
