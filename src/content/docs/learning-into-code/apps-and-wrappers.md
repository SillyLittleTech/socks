Different app approaches fit different goals.

| Approach | Useful when | Examples |
| --- | --- | --- |
| Web app | You want easy access from browsers | Astro, Vue, React, Svelte |
| Native app | You need platform APIs or deep integration | Swift, Kotlin, .NET MAUI |
| Wrapper app | You want web UI with desktop or mobile packaging | Tauri, Electron, Flutter |

## Practice vs production

Practice projects can skip distribution, updates, signing, telemetry, and support. Production apps need those decisions made deliberately.
