Free tiers can be generous, but they still deserve respect.

## Useful categories

- Static hosting: Cloudflare Pages, Vercel, Netlify, GitHub Pages.
- App platforms: Fly.io, Render, Railway, Firebase, Supabase.
- CMS tools: Keystatic, Decap CMS, TinaCMS, Sanity.
- Code tools: VS Code, GitHub Codespaces, StackBlitz, CodeSandbox.
- Quality tools: linters, formatters, code scanning, dependency alerts.

## Free tier habits

Read limits before relying on a service. Track which account owns the project, what happens when limits are exceeded, and how you would export the data.
