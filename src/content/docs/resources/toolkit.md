This is a starter toolkit, not a shopping list.

## Accounts

- Password manager.
- Passkeys where supported.
- Hardware security keys for high-value accounts.
- Backup codes stored somewhere safe.
- Recovery details checked twice a year.

## Browsing

- Reputable ad blocker.
- Separate browser profiles.
- Minimal extensions.
- Reader mode or reader extensions when pages are hostile to focus.

## Money

- Virtual cards or payment aliases.
- Spending limits for recurring services.
- Merchant-specific cards when possible.
- Account alerts for unusual transactions.

## Building

- Git and a hosted Git platform.
- Static hosting for simple sites.
- A CMS when non-code editing matters.
- Code scanning and dependency alerts.
- A written line between practice and production.
